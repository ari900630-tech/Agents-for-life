# Agents for Life

אפליקציית AI Agents מותאמת לטלפון: יוצרים סוכנים עם הוראות משלהם, כותבים משימה בשפה טבעית ומפעילים אותם.

## מה כבר קיים
- ממשק RTL בעברית ומותאם למסך טלפון.
- יצירה ושמירה מקומית של סוכנים מותאמים אישית.
- הפעלת משימה מול OpenAI Responses API.
- חיפוש אינטרנט אופציונלי לכל משימה.
- היסטוריית משימות מקומית.
- API key נשמר בצד השרת דרך משתנה סביבה ולא בקוד.

## הפעלה
1. התקן Node.js 20 ומעלה.
2. הרץ `npm install`.
3. הגדר `OPENAI_API_KEY` במשתני הסביבה.
4. אפשר לבחור `OPENAI_MODEL`; ברירת המחדל היא `gpt-5.6-luna`.
5. הרץ `npm start` ופתח את הכתובת שהשרת מציג.

לפרויקט יש API server ולכן אין לשים מפתח OpenAI בתוך `public/` או בקוד הדפדפן.

## כיוון ההרחבה
הארכיטקטורה מאפשרת להוסיף לסוכנים כלים נוספים, אינטגרציות ופעולות מאומתות. פעולות חיצוניות אמיתיות צריכות חיבור והרשאות מפורשות לשירות המתאים.
